# University of Buenos Aires Projects

## Overview



This repository contains a curated collection of computer science, physics, and scientific computing projects developed during my undergraduate and postgraduate studies at the University of Buenos Aires.



The projects cover:



* algorithms and data structures,
* scientific computing,
* machine learning,
* numerical methods,
* low-level programming,
* complex systems simulations,
* and scientific report automation using LaTeX and Python.



The repository includes work developed in:



* Python,
* Java,
* Haskell,
* RISC-V Assembly,
* LaTeX,
* and Jupyter Notebooks.

## Installation

**Main Requirements**



Depending on the project, the repository may require:



* Python 3.10+
* NumPy
* Pandas
* Matplotlib
* PyTorch
* Jupyter Notebook
* Java
* Haskell
* LaTeX distribution
* Logisim
* RISC-V toolchain



Install common Python dependencies with:

```
pip install numpy pandas matplotlib torch notebook
```

## Usage

Most Python-based projects can be executed using:



```
python main.py
```



or through Jupyter Notebook:



```
jupyter notebook
```

Java projects follow a standard Maven-like structure and include unit tests.
